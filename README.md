## 建站卡住的地方，往往不在配置单上

很多人买服务器的顺序是错的：先看几核几 G，再看价格，最后才想起线路。等网站真的跑起来才发现，白天测试一切正常，晚上八点一到页面加载变成开盲盒。

普通国际线路的流量要绕好几个节点才进大陆，晚高峰这些节点最容易拥堵。线路优化过的服务器走的是不同的骨干路由，比如电信的 CN2 GIA（AS4809）、联通的 AS9929、移动的 CMIN2（AS58807）。这些是运营商自己的精品网，带宽资源有限，卖得贵，但高峰期的表现和普通线路不在一个量级。

DMIT 在这件事上的位置比较特殊。它是一家注册在美国纽约的服务商，机房覆盖洛杉矶、香港、东京，产品线按线路分成 Premium、Eyeball、Tier 1 三档。圈子里的评价集中在两点：一是与中国三大运营商直签带宽，二是承诺不超售——你买 2GB 内存，独占的就是 2GB，不会因为是共享物理机被别人抢走。

还有个说法值得单独提：有测评提到搬瓦工的部分 CN2 GIA 带宽是从 DMIT 采购的。这说明它在高端线路资源上有实际的上游能力，不是单纯转卖。

## 三条线路的差别，比配置单更值得研究

DMIT 的套餐命名里最容易被忽略的就是中间那两个字母。搞清楚它们，选套餐基本就不会错。

**Premium（.Pro）** —— 三网回程走 CN2 GIA。以洛杉矶为例，电信去程走 GIA（AS4809），联通去程直连 AS4837，移动去程经香港移动（AS58453），三网回程统一 GIA。这是面向中国大陆优化最好的档位，价格也最高。

**Eyeball（.EB）** —— 回程以 CMIN2 为主，电信方向在 AS9929 与 AS58807 之间做负载分配，联通主要走 AS9929，移动走 AS58807。比 Pro 差一档，但同价位给的月流量通常更多，移动和联通用户感受尤其明显。

**Tier 1（.T1）** —— 纯国际 BGP 路由，接 RETN、NTT 这类国际骨干，欧洲到亚洲延迟表现好，但**没有针对中国大陆做任何优化**。电信用户买 T1 有可能出现延迟比美西还高的情况。

硬件平台代号也顺带记一下：AS3 是 AMD EPYC 7003 系列，AN4 是 EPYC 9004（9654），AN5 是 EPYC 9005。平台越新单核性能越强，但价格也往上走。此前美西 AN5 系列曾因全球硬件成本上涨被暂停销售，之后又补货，库存状态本身就不稳定。

## 建什么站，决定你该买哪一档

这里没有统一答案，但有几条经验值可以参照。

**1 核 1G / 1 核 2G** —— 静态页面、单页官网、低频更新的展示站。Linux.do 上有用户提到用 1 核 1G 装宝塔再跑 WordPress，日常运营是流畅的，前提是访问量不大。

**2 核 2G / 2 核 4G** —— 大多数人的起点。WordPress 装了缓存插件、图片压缩之后再挂个统计脚本，2G 内存是舒服的线。宝塔面板官方文档里对 Docker 部署 WordPress 的建议也是内存 2GB 以上。

**4 核 4G 起步** —— WooCommerce、多站点、需要跑 MySQL 且不想频繁调优的场景。数据库和 PHP-FPM 都是吃内存的，这时候省内存等于省自己的时间。

**硬盘别只看大小** —— WordPress 站点的体积增长主要来自图片和备份。20GB 起步做博客够用，但只要涉及产品图库或者定期本地备份，40GB 是更稳的选择，不然半年后就要考虑扩容。

## 从开机到网站上线，关键动作在哪

服务器层面的事情其实不多，容易出问题的是下面这几步。

**第一步，开机后先做基础加固。** 改 SSH 默认端口、禁用密码登录只留密钥、开防火墙。这一步省掉，服务器上线几小时就会开始被扫描。

**第二步，装面板。** 宝塔面板对中文用户的友好度更高，环境套件选 LNMP（Nginx + MySQL + PHP），PHP 版本按 WordPress 官方要求选新一些的。不想装面板的话，用 Docker 部署也能把环境隔离得干净，宝塔官方文档里就有 WordPress 一键安装的命令。

**第三步，域名解析和 SSL 一起做。** 海外机房不需要备案，域名解析过去就能访问，这是个实打实的便利。Let's Encrypt 的免费证书现在申请和续签都能自动化，没有理由再跑 HTTP。

**第四步，CDN 按需上。** 如果访客分布在国内多个省份，套一层 Cloudflare 之类的 CDN 能缓解跨运营商的问题。但要注意，CDN 会改变回源路径，线路优化的收益可能被部分抵消，需要实测确认是不是真的变快了。

**第五步，备份要离开这台机器。** 定时任务把数据库和网站目录打包推到对象存储或者另一台机器上。备份和站点放同一台服务器，等于没备份。

## 几个建站前应该知道的限制

**流量超了会限速，不会断网。** DMIT 从 2025 年 2 月起执行限速不停机策略，流量用完后端口降到指定速度继续跑，不同套餐的限速值从 4Mbps 到 100Mbps 不等。对建站来说这比直接停机友好得多——突发流量最多把网站变慢，不会让站点直接下线。

**流量按双向计算。** 这是容易被忽略的一点。高流量站点做预算时要按进出之和估算，不能只看访客下载量。

**换 IP 有节奏。** 第三方介绍普遍提到每 15 天可免费更换一次 IP，超出频率按次收费。如果网站域名已经解析好、邮件服务也挂在上面，换 IP 是有连带成本的，别把它当成日常操作。

**维护通知不一定发。** 有测评指出 DMIT 在做宿主机升级时通常不提前发邮件，服务器可能短暂不可用。对 SLA 有硬性要求的业务，这一点需要提前考虑。

**付款方式对国内用户友好。** 支付宝、PayPal、信用卡都是常规选项，第三方介绍里也提到支持微信支付。对建站来说，能不能顺利付款其实是个挺实际的门槛。

## 常见问题

**建站一定要用 Pro 吗？**

不一定。如果网站访客大部分在海外，或者你对 150ms 和 40ms 的差别没有感知，T1 和 EB 能省下相当一部分预算。Pro 的价值在面向国内用户的场景里才充分体现。

**1 核 1G 能建站吗？**

能，前提是站点轻量、访问量不大、缓存配好。但这是一条会被很快走完的路——插件多装几个、图片不压缩，内存就吃紧了。第一次买建议直接从 2G 内存起步。

**香港 Pro 比洛杉矶贵这么多，值吗？**

如果你的日常操作包含频繁登录后台、改内容、看数据，香港 20–50ms 的延迟省下的是每天累积的时间。如果只是部署完就不怎么动的展示站，这笔溢价不一定花得值。

**会不会经常缺货？**
